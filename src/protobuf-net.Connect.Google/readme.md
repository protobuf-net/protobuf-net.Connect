# protobuf-net.Connect.Google

Canonical protobuf JSON for [Connect](https://connectrpc.com) services whose
messages are `Google.Protobuf` types — i.e. contract-first, generated by `protoc`.

**Documentation: [connect.protobuf-net.dev/json](https://connect.protobuf-net.dev/json)**

```csharp
builder.Services.AddConnect(o =>
{
    o.Codecs.Add(MarshallerConnectCodec.Instance);   // application/proto
    o.Codecs.Add(GoogleJsonConnectCodec.Instance);   // application/json
});
```

A separate package so that `Google.Protobuf` stays off `protobuf-net.Connect`'s dependency graph: a
code-first consumer has no Google messages and no reason to carry it.

The mapping is Google's own `JsonFormatter`/`JsonParser`, not a reimplementation — there is exactly
one correct implementation of the canonical mapping per world, and the mapping is far too detailed to
want a second. Code-first contracts get their JSON generated instead, and need nothing from here.
